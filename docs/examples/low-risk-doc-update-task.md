# 示例任务：更新 README 中的项目目标描述

> 低风险试跑样例。仅作填写示范，不代表已执行该改动。

## 任务标题

更新 README 中的项目目标描述

## 背景

项目入口 `README.md` 已有目标说明；若表述需更准确或与 `docs/ai-workflow.md` 对齐，做一次文案微调即可验证文档类低风险任务的闭环流程。

## 目标

在不改动其它章节的前提下，更新 `README.md`「项目目标」段落的表述，使其更清晰、与现有闭环文档一致。

## 影响范围

- 模块 / 目录：项目根目录文档
- 预计改动文件：`README.md`（仅「项目目标」小节）
- 可能波及的调用方：无（纯文档）

## 不做什么

- 不修改业务代码
- 不调整分工表、流程、文档索引等其它 README 章节
- 不新增依赖、不改 CI、不改规则文件

## 验收标准

- [ ] 仅修改 `README.md` 中「项目目标」相关文案
- [ ] 其它章节与链接保持不变且可点击
- [ ] Markdown 标题层级与列表格式正确
- [ ] PR / 回复中说明改了什么、为什么、有无风险

## 测试命令

```text
无需运行测试，仅检查 Markdown 链接和格式
```

## 风险等级

低

## 推荐执行者

Cursor 或 Codex

## 完成后需要说明的内容

- 改了哪个文件：`README.md`
- 为什么改：对齐 / 澄清项目目标表述
- 是否有风险：无（纯文档文案，可随时回滚该段）
- 测试命令与结果：已人工检查 Markdown 链接与格式
- 残留风险 / 待确认项：无
