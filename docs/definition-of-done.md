# Definition of Done

任务或 PR 在满足以下全部条件后，才视为完成。

## 必备项

- [ ] **需求明确**：目标、边界、验收标准已写清，无关键歧义未决
- [ ] **修改范围清楚**：拟改 / 已改文件与模块可列出，无无关改动
- [ ] **测试通过**：相关测试 / 校验已跑且通过；未跑须说明原因与替代验证
- [ ] **风险说明完整**：权限、支付、数据库、用户数据、配置等影响已评估并写明
- [ ] **高风险变更人工确认**：涉及上述高风险面时，已获得人工确认记录
- [ ] **PR 描述完整**：含变更总结、验证结果、风险与回滚方案（对照 `PR_CHECKLIST.md`）

## 快速判定

| 问题 | 未满足时 |
|------|----------|
| 还不知道“不做什么”？ | 未完成，先回 GPT 澄清 |
| 改动文件说不清为什么需要？ | 未完成，缩小范围 |
| 测试没跑也没说明？ | 未完成 |
| 高风险改动无人确认？ | 未完成，禁止合并 |
| PR 缺少验证或回滚说明？ | 未完成 |
