# 任务模板

复制下方模板填写。一项任务只做一件事；边界不清时先回 GPT 澄清。

```markdown
## 任务标题

（一句话说明要做什么）

## 背景

（为什么要做，相关上下文 / 缺陷 / 告警）

## 目标

（完成后应达到的结果）

## 影响范围

- 模块 / 目录：
- 预计改动文件：
- 可能波及的调用方：

## 不做什么

- （明确排除项，防止范围扩散）

## 验收标准

- [ ]
- [ ]

## 测试命令

```text
（例如：npm test / pytest path/to/test）
```

## 风险等级

低 / 中 / 高

（高风险示例：权限、支付、数据库迁移、用户数据、生产配置、安全相关）

## 推荐执行者

GPT / Codex / Cursor / 人工

（可多选，主执行者写在前；分流规则见 `docs/ai-task-routing.md`）

## 完成后需要说明的内容

- 变更总结（改了什么、为什么）
- 实际改动文件列表
- 测试命令与结果
- 残留风险 / 待确认项
- 是否需要人工复核或回滚方案
```
