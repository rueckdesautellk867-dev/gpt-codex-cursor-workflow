# T012 配置 main 分支保护

- **编号**：T012
- **状态**：已完成
- **风险等级**：中
- **推荐执行者**：人工（GitHub 网页管理员权限）

## 任务标题

配置 `main` 分支保护，让 CI 结果成为合并门槛。

## 背景

T006 已接入真实 CI，检查名为 `Docs validation`。为了避免后续直接裸推 `main` 绕过 CI，需要在 GitHub 网页开启分支保护。

## 目标

在 GitHub 仓库中保护 `main`：

- 禁止未经过 PR 的直接合入
- 要求 `Docs validation` 通过
- 要求分支与 `main` 保持最新
- 禁止 force push 和删除分支

## 影响范围

- GitHub 仓库设置
- `main` 分支合并流程
- 后续日常闭环：本地改动 → 分支/PR → CI → 合并

## 不做什么

- 不修改业务代码
- 不执行 T004 高风险样例
- 不替代人工审批流程
- 不配置云端部署、监控或外部任务系统

## 完成记录

- 已由人工在 GitHub 网页开启分支保护。
- 必选状态检查：`Docs validation`
- T004 仍保持 `待确认`。
